# upwork_analytics

Starter repository for Google Apps Script code used in Upwork analytics workflows.

## Structure

- `src/Code.js`: Main Apps Script source file.
- `src/appsscript.json`: Apps Script project manifest.

## Next Steps

1. Add your script logic in `src/Code.js`.
2. Update `src/appsscript.json` scopes/timezone as needed.
3. (Optional) Use `clasp` to push/pull with Apps Script.
